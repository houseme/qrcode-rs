# v2.1.0 之前版本功能核查与未实现列表

日期: 2026-09-07

## 核查范围

- 文档: `docs/roadmap.md`, `docs/roadmap/v0.2.0-*` 到 `docs/roadmap/v2.0.0-*`, `docs/v*.0-implementation-plan.md`, `docs/v2.0.0/*`, `CHANGELOG.md`, `README.md`, `MIGRATION-1.x-to-2.0.md`
- 代码: `src/`, `crates/`, `tests/`, `examples/`, `fuzz/`, `.github/workflows/`
- 版本边界: v2.1.0 之前的历史版本功能,并额外标注 v2.1.0 文档状态漂移,因为当前仓库版本已经是 `2.1.0`

## 结论

v0.2.0 到 v2.0.0 的已发布核心功能大多已在代码、示例或测试中落地。未完成项主要分两类:

1. 历史路线图中后来明确延期的扩展能力,不应再算作对应版本发布阻塞项。
2. 文档状态没有随实现同步,会让读者误以为某些已实现功能仍未完成。

## 文档状态不一致

- 核查时 `docs/roadmap.md` 当前版本仍为 `v2.0.0`,但 workspace 版本已经是 `2.1.0`;本轮已同步。
- 核查时 `docs/roadmap.md` 中 v2.1.0 状态仍为待开始,但 `CHANGELOG.md` 与 `docs/v2.1.0-implementation-plan.md` 已记录当前实施状态;本轮已同步。
- 核查时 `docs/roadmap.md` 的“待补充示例”列出的 Kanji、ECI、FNC1、自定义颜色、Structured Append 示例均已存在于 `examples/`;本轮已同步。
- 核查时 `docs/roadmap/v1.4.0-advanced-interop.md` 顶部写 Core 已完成,但发布检查清单仍全部未勾选;本轮已同步为已实现/延期分项。

## 已确认实现的代表性能力

- v0.2-v0.3: Micro QR、EPS/PIC/HTML/PDF/Unicode/ANSI/SVG 增强与集成测试。
- v0.4: CLI、builder、便利构造函数、FromStr、rows/dark_modules、错误上下文。
- v0.5: GS1/FNC1、`Info`、mask/mode/remaining-capacity metadata、alt text、SVG/HTML ARIA、forced mode。
- v0.6: Criterion bench、parser-boundary DP segmentation、`colors()` 零拷贝 borrow、`Color #[repr(u8)]`、`QrCode: Send + Sync`。
- v1.0-v1.3: missing docs gate、serde、no_std + alloc、batch/template、log facade、`analyze()`、`QrError::suggestion()`。
- v1.4-v1.6: parse WiFi/vCard/GS1、decode trait、rqrr adapter、Structured Append encode/reassemble、SA bit-stream parser、rqrr EC-level fix。
- v2.0: workspace split、core/render/parse/decode/backend crates、core traits、plugin registry、typed helpers、module views、async render、stream API、compat migration layer。

## 本轮补全优先级

1. 修正 `docs/roadmap.md` 的当前版本、v2.1.0 状态与已存在示例清单。
2. 修正 `docs/roadmap/v1.4.0-advanced-interop.md` 发布检查清单,区分 Core 已完成与延期范围。
3. 补齐 `deterministic` feature 与 `QrCode::new_deterministic` 显式入口。
4. 补齐 `Info::mask_pattern()` / `Info::mask_penalty_score()` 与 core mask 选择元数据接口。
5. 补齐 `Info::encoding_modes()`、`Info::remaining_capacity()` / `remaining_capacity_bits()` 与 core encoding metadata。
6. 补齐 `ResourceLimits::encoding_timeout` 字段与同步构造边界检查。
7. 将 Parser segment 边界上的模式合并替换为动态规划。
8. 补齐 `parallel` feature、`QrCode::par_batch`、`QrCode::batch_render`、CLI CSV/JSON/JSONL batch、并行 batch 渲染、ZIP/grid batch 打包和 `qrencodes validate`。
9. 补齐库级 `QrCode::batch_builder`、store/DEFLATE ZIP bytes 与 PNG grid/contact sheet bytes。
10. 补齐 `QrTemplatePatch` 继承/覆盖 API。
11. 补齐 `template-json` feature,支持 `QrTemplate` / `QrTemplatePatch` JSON 读写。
12. 优化通用渲染热路径,跳过 quiet-zone 背景格遍历,并减少 Unicode/ANSI/PDF 输出中间分配。
13. 扩展 rendering benchmark 覆盖 Unicode/ANSI/HTML/PIC/PDF 后端。
14. 补强 v2.1.0 unsafe/SIMD 审计可读性:让保留的 `unsafe` 均有清晰 `SAFETY:` 说明。
15. 运行 focused 文档/代码验证,确认补全没有破坏当前实现。
